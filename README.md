# Arduino Traffic Light

A beginner embedded systems project built using Arduino Uno and Tinkercad.

## Features

- Red light state
- Yellow light state
- Green light state
- Red + Yellow transition state
- Implemented using Arduino digital outputs and delay timing

## Components

- Arduino Uno
- Breadboard
- 3 LEDs (Red, Yellow, Green)
- 3 Current Limiting Resistors
- Jumper Wires

## Concepts Learned

- GPIO pins
- pinMode()
- digitalWrite()
- HIGH and LOW logic levels
- delay()
- Breadboard connections
